1- Diferencia Entre Int y Num:
    Int solo abarca a los enteros, no admite a los decimales, tambien ocupa un espacio reducido en la memoria y suele ser mas rapido para conteos y operacioneslògicas.
    El num abarca a todos los numeros o valores numericos y permite definir decimales exactos a cambio de un gran consumo de la memoria.
